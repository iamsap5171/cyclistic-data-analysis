# Cyclistic Bike-Share Data Analysis 🚲

## 📌 Project Overview

This project analyzes the behavior of Cyclistic bike-share users to understand the differences between casual riders and annual members.

The goal is to identify patterns in usage and provide business recommendations to convert casual riders into members.

---

## 📊 Tools Used

* SQL (MySQL Workbench)
* Excel (Data Visualization)

---

## 📂 Dataset

The dataset contains ride data including ride duration, user type, and timestamps.

---

## 🔍 Key Insights

* Members take significantly more rides, indicating frequent usage.
* Casual riders have longer average ride durations, suggesting leisure usage.
* Members show consistent weekday activity, while casual riders are more active on weekends.

## 💡 Recommendations

* Target casual riders with weekend promotions.
* Offer trial memberships to convert occasional users.
* Highlight cost benefits of membership plans.

---

## 🚀 Conclusion

This analysis shows clear behavioral differences between casual and member riders, providing actionable insights for marketing and growth strategies.
